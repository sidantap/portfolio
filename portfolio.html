-- 02 ai and llms

AI and LLM projects

I started working with language models in 2024, training them in a university research lab. Today I build software alongside AI agents every day.

fine-tuning an llm · research poster · 2024with Simran Shrestha, Pheo Ward and Dr. Junxiu Zhou · NKU School of Computing & Analytics

An NKU chatbot built on a fine-tuned LLM

The goal was an LLM tailored to Northern Kentucky University that answers NKU questions quickly, saving people time and making NKU information easier to reach. I wrote a Python program that collected HTML from the NKU website and saved it as text with the help of Jina AI's reader. We cleaned that text into 1,611 samples, then converted each one into instruction, input and output form using GPT-4o, with manual review. We fine-tuned GPT-2, a 1.5-billion-parameter transformer, on that dataset. Training took more than six hours on a standard CPU laptop.

  2. extract text (Jina)
  3. clean → 1,611 samples
  4. instruction / input / output (GPT-4o + manual)
  5. fine-tune GPT-2
  6. compare with ChatGPT

comply. a system of record for DOT drug and alcohol testing

Employers that run DOT random testing often keep the pool in spreadsheets and send it to an outside administrator they can't see into. comply keeps that program in one place, from the HR system to the inspector.

It syncs employees from the HR system and routes every pool change through an approval queue with the HR reason attached. It runs random selections that anyone can re-run to prove they were fair, then tracks each test from the notice and nearest open collection site to the MRO result. Person-level alerts flag what the FAA has actually fined employers for in 2026, and the audit report and draft MIS numbers are always ready for an inspection. The program manager makes every decision; the software keeps the record.
