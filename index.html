-- 01 about

Before a number reaches a meeting, I want to know where it's been.

My path has gone freight, then clinical research, then aviation, then a public water utility. On paper those have little in common. In practice every one of them had the same quiet problem: the data lived in four or five systems, the systems disagreed, and someone was reconciling it by hand every Monday.

At Motus Freight I learned what a KPI is worth when nobody trusts the inputs. At Medpace I worked with clinical datasets that ran to millions of records, where a bad join is a scientific problem, not a cosmetic one. At Atlas Air I built an FAA testing app where every rule had to survive an audit. At the Northern Kentucky Water District I own the path from SAP and Lucity to the reports that HR, Legal, Engineering, IT, Customer Service, Finance and Operations open each morning.

I'm happiest in the middle of that path: tracing a failed Data Factory run to the row that broke it, deciding what grain a fact table should have, and writing the documentation so the next person doesn't need me. I studied Computer Information Technology at NKU and graduated summa cum laude in December 2025.

Upstream

Ingesting from SAP, Lucity, Medidata and SharePoint with SSIS, Azure Data Factory, Graph API and scheduled SQL Server Agent jobs.

Midstream

Staging, cleaning and conforming in T-SQL, dbt and Databricks, then modeling it into facts and dimensions people can query without a guide.

Downstream

Power BI, Tableau, R Shiny and Power Apps on top, with gateways, refresh schedules and training so the thing keeps working after launch.

-- 05 ai

I was fine-tuning language models before I was building with them.

My AI work started in a university research lab, teaching a model to answer questions about NKU. Now I build software alongside agents every day.

Teaching a model about one campus

For NKU's information chatbot I gathered and shaped 1,600+ question and answer examples from university web content, then fine-tuned GPT-2 and a custom 1.5B-parameter model in TensorFlow on AWS EC2 and S3. NKU-specific answers got 10 to 15% more accurate.

Reading how people feel

For a nursing study I built an NLP pipeline that reads forum posts from first-year nurses and sorts them into stress, depression, workplace and wellbeing themes. Finding meaning in unstructured language is the part of AI I find most interesting.

Working with agents

I build with Claude Code, splitting work across subagents for research, implementation and review, and writing my own skills so an agent follows the same process every time. GitHub Copilot covers the small stuff in the editor. This site was built that way.
