-- 02 what I build

The whole path, from a source system to a decision.

Here it is as a pipeline I run in public every night. Each step lights up as you scroll, and the numbers come from its latest run.

Ingest

Pull only what changed since the last run, from APIs, SAP or SQL Server.

Land

Keep every row exactly as it arrived, so any number can be traced back.

Clean and test

One version of each record, checked by tests. Bad rows go to quarantine with a reason.

Model

A star schema people can query without a guide.

Serve

Dashboards, apps and, here, an open-source model classifying complaints.
